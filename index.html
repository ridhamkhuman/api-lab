What is an API?

An API is a menu of URLs a server exposes. You send a request; it returns data (usually JSON).

01 Client

Browser, Postman, or your app builds a request.

→
02 Request

Method + URL + headers + optional body.

→
03 Server

Checks auth, runs logic, talks to a database.

→
04 Response

Status code (200, 401…) + JSON / text / file.

HTTP methods

Same URL can mean different actions depending on the method — like verbs for the web.

Collections

Query params append to the URL as ?key=value. Example: ?_limit=3

An API key is a secret string the provider gives you. You send it in a header (or query) so the server knows who is calling. Never commit real keys to git or share them in chat.

Basic Auth encodes username:password as Base64 and sends Authorization: Basic …. Demo server: httpbin expects user postman / pass password.

Bearer tokens (often JWTs) go in Authorization: Bearer <token>. Used by OAuth / login APIs.

Custom headers merge with auth headers when you Send.

Authorization cheat sheet

Three patterns you’ll see every week in Postman and real products.

API Key

Provider gives you a long secret. You paste it into Postman → Authorization → API Key, or a header like X-Api-Key.

X-Api-Key: your_key_here

Username + password

Basic Auth. Postman has a “Basic Auth” type — fill user/pass; it builds the header for you.

Authorization: Basic cG9zdG1hbjpwYXNzd29yZA==

Bearer / OAuth

Login once, get a token, send it on every request until it expires.

Authorization: Bearer eyJhbGciOi…

So… what is an API key?

It is not something this page invents for you. A real product (Stripe, Maps, OpenAI, your company’s gateway) generates a key in their dashboard. You copy it into Postman once, store it as an environment variable, and never paste it into public chats or GitHub.

In this lab, the “API Key demo” shows the shape of the header. The free APIs above work without a key so you can learn safely.

Postman UI map

When you open real Postman, these are the same zones you just used.

  1. New → HTTP Request — blank request, like our playground.
  2. Method dropdown + URL bar — choose GET/POST/… and paste the endpoint.
  3. Params / Authorization / Headers / Body tabs — same tabs as above.
  4. Send — fires the call; Body / Pretty shows JSON.
  5. Environments — store {{baseUrl}} and {{apiKey}} so secrets stay out of the URL field.
  6. Collections — group requests for your team (Users, Auth, Orders…).
